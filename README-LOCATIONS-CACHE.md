# تحديثات النسخة

تم إصلاح زر تحديث البيانات وإضافة إمكانية إنشاء بيانات جديدة في Locations.

## 1) زر تحديث البيانات
تم إصلاح إعادة بناء القوائم بعد التحديث. القوائم تعتمد مباشرة على `DB.locations`:
- المحافظة
- المنطقة
- اسم المحل

كما تم رفع إصدار الكاش إلى `v11-offline-locations` حتى لا تبقى النسخة القديمة في الهاتف.

## 2) إضافة بيانات جديدة إلى Locations
أصبح بجانب كل قائمة زر `+`:
- + بجانب المحافظة: إضافة محافظة جديدة.
- + بجانب المنطقة: إضافة منطقة تحت المحافظة المختارة.
- + بجانب اسم المحل: إضافة محل تحت المحافظة والمنطقة المختارتين.

يتم منع التكرار، وبعد الحفظ يتم تحديث الكاش تلقائياً وتحديد القيمة الجديدة.

### مهم: تعديل Google Apps Script
النسخة المرفقة لا تحتوي `Code.gs` الأصلي، لذلك يوجد ملف:
`Code.gs-location-addition-patch.txt`

طبّق الـ patch في `Code.gs` الحالي:
1. داخل `doPost` أضف case `addLocation` كما هو موضح في الملف.
2. أضف دالة `addLocation` كما هي.
3. انشر Google Apps Script كـ New version.

## 3) تحديث الكاش بعد كل تقرير
بعد نجاح إرسال التقرير أونلاين يتم استدعاء `refreshAppCache({silent:true})` تلقائياً.
وعند مزامنة تقارير Offline بنجاح، يتم أيضاً تحديث الكاش مرة واحدة بعد اكتمال المزامنة.
