الموقع الجديد - نسخة مبنية على الموقع الأول

التعديلات:
- حذف نوع الحملة.
- حذف نوع الحدث.
- حذف عدد أيام الحدث.
- حذف تبعية الجرد.
- حذف منسق النقطة.
- المشرف أصبح قائمة منسدلة.
- الأشخاص المتواجدون بجانب المشرف.
- إزالة كل ما يتعلق بالباركود والكاميرا والـ USB Scanner.
- المبيعات تعتمد على تصنيف المادة "مادة بيعية".
- المصاريف تعتمد على تصنيف المادة "مادة تذوق".
- المصاريف: مادة + كمية + ملاحظات + حسم + إجراء.
- الحسم يقبل قيمة مثل 10% أو "مجانا".
- إضافة قسم كامل للهدايا بنفس أعمدة المصاريف.
- Offline mode والكاش وتحديث البيانات ما زالت موجودة.
- بعد كل إرسال ناجح يتم تحديث الكاش تلقائياً.
- Service Worker version: v12.

مهم:
الملف المرفوع الأصلي لا يحتوي Code.gs، لذلك أضيف ملف BACKEND-NEW-STRUCTURE.txt لتوضيح التعديلات المطلوبة على Google Apps Script.
