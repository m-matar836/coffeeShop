# V17 — فلترة المواد حسب الفرع

تم ربط المواد بعمود `point` في ورقة `Products`. بعد اختيار **اسم الفرع** من
معلومات التقرير الأساسية:

- قائمة مواد المبيعات تعرض مواد الفرع المحدد فقط.
- قائمة الضيافات والهدر تعرض مواد الفرع المحدد فقط.
- البحث بالباركود يستخدم نفس فلترة الفرع.
- عند تغيير الفرع تُحذف من التقرير الحالي المواد التي لا تتبع للفرع الجديد.

يمكن وضع أكثر من فرع في خلية `point` باستخدام فاصلة عربية أو إنجليزية أو
فاصلة منقوطة أو سطر جديد. وتُقبل أيضًا قيم `كل الفروع` و`شاملة`.

بعد رفع النسخة، انسخ `code.gs.txt` إلى Google Apps Script وانشر نسخة جديدة
من Web App حتى يتم تحميل عمود `point` من Google Sheets.
